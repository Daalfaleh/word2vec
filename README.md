# Topic Modelling with Word2Vec

A Jupyter notebook that explores topic discovery from ABC News headlines using Word2Vec-style word embeddings. The repository includes the headline dataset and the analysis notebook.

## Files

- `abcnews-date-text.csv` — dated news headlines
- `topic_modelling_using_word2vec.ipynb` — preprocessing, embedding, and topic-analysis workflow

## Use

Create a Python environment with Jupyter and the libraries imported in the notebook, open the notebook, and run the cells in order. Because the dataset is included, the analysis can be reproduced locally.
